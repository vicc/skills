# Audit Skills

Find out which Codex skills are installed, which ones appear in your recorded chats, and how much context their descriptions take up at the start of a chat.

## Install

```bash
npx skills@latest add vicc/skills --agent codex --skill vicc-audit-skills
```

## Try it

> Use $vicc-audit-skills to show my ten most-used skills and when I last used each one.

Usage counts depend on the chat history available locally. You can also ask for cleanup candidates and review the list before deciding what to remove.
