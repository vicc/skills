# Cook

Use Cook when you want Codex to implement a feature, fix, or prototype. It starts with one real user flow, checks that it works, then finishes the agreed scope.

## Install

```bash
npx skills@latest add vicc/skills --agent codex --skill vicc-cook
```

## Try it

> Use $vicc-cook to add a rename action to the project list. Make sure the new name is still there when I reopen the project.

Open the project in Codex and describe what a user should be able to do. Cook follows the project’s required checks and asks about choices that would change product behavior, cost, or access.
