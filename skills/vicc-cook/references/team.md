# Delegation and ownership

Use the lead alone for a small edit. Delegate independent, bounded work when it saves time or improves verification of the requested flow. Follow live host limits and preserve the user's model choices. Select a named role through the supported role field when available. If the host has no role field, pass the installed role instructions with the assignment when available.

| Agent | Use when |
| --- | --- |
| `cook_product_manager` | Requirements or acceptance criteria need focused product judgment |
| `cook_architect` | A significant boundary, dependency, or architectural risk needs resolution |
| `cook_ux_designer` | User flows, states, or interactions need design |
| `cook_ui_figma_designer` | A supplied Figma source or design system needs faithful implementation |
| `cook_ios_engineer` | Swift/iOS implementation is on the critical path |
| `cook_frontend_engineer` | Web UI implementation can be isolated |
| `cook_backend_engineer` | Server logic, storage, or APIs can be isolated |
| `cook_integration_engineer` | Systems need an agreed contract and working end-to-end connection |
| `cook_qa_engineer` | Focused regression or journey validation can run on completed code |
| `cook_security_privacy` | Material trust boundaries or sensitive data merit review |
| `cook_accessibility` | Changed interactions need keyboard, assistive technology, or contrast review |
| `cook_performance` | A measured or credible performance risk needs bounded investigation |
| `cook_devops_ci` | Build, CI, or local operational configuration needs work |
| `cook_code_reviewer` | A completed slice needs independent correctness review |

Assign one outcome, observable acceptance criteria, agreed contracts, exclusive files or modules, allowed actions, focused verification, and a stop condition. Have each agent report the result, changed paths, evidence, and blockers. Use isolated worktrees when concurrent edits cannot be separated by file. Keep one integration owner who verifies the combined flow.

Give agents the same scope and decision boundaries. Route consequential unresolved choices through the lead to the user. Keep further delegation under the lead's coordination. Reuse workers for related work and close finished workers when practical.
