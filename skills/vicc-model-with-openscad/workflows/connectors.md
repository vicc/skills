# Mechanical connectors

1. **Identify the job.** Is the part holding a load, guiding motion, retaining a removable part, or compressing a seal? Use the [connector selection table](../references/connector-selection.md) to match the mechanism to that job. For an unspecified mechanism, recommend one option and two fallbacks. For a named mechanism, preserve it and flag alternatives only if a requirement cannot be met.
2. **Set the fit before drawing.** Establish process, nozzle or material, load, expected cycles, environment, and service access when they affect dimensions or failure risk. Ask only for missing decisions that change the result. For a quick concept with missing specs, state the assumptions: indoor light-duty FDM, 0.4 mm nozzle, PETG for snaps, service access, and the general moving-fit default of 0.25 mm total clearance (0.125 mm per side for a centered two-sided fit). Use explicit user dimensions first, then the mechanism-specific [geometry recipe](../references/geometry-recipes.md), then the general [process guidance](../references/dfam-heuristics.md). State whether each clearance is per side, radial, or total. If a requested clearance is ambiguous, state the convention you used.
3. **Draw the mating pair.** Put dimensions and fit values in named millimeter parameters. Inspect the [module library](../assets/cad/mechanical_connectors.scad) for a matching module and reuse it only if its shape and parameter behavior meet the requested fit. The stock `snap_tab()` example can export the root, beam, and hook as separate bodies. Check connected solids before reusing it and make the tab one continuous body. For a standalone deliverable that depends on the library, include a local copy and import it with `use <mechanical_connectors.scad>` so the file works outside this skill. Add mating stops and gradual root transitions where required. For flexing latches, identify the bend plane and orient it in XY so the flexure loads continuous filament paths. Make the stop limit overtravel and route the installed load through a shoulder, rail, or pin where the latch would otherwise bear the load in bending. For a sealed closure, include a gasket or O-ring and a compression stop because printed plastic contact is not a reliable seal.

   For a dovetail, define the rail profile and the receiver cut from the same cross-section. The widest part of the rail sits farthest from its base and the widest part of the groove sits deepest from its opening. Mirror the cutter when the receiver prints with the channel facing up.

4. **Make a fit coupon.** Use the same mating profile and parts orientation as the full design. For a slide, shorten the rail and receiver while keeping the cross-section and clearance. For a snap, preserve the beam, hook, catch, root geometry and stop that control deflection. State the orientation, support or finishing needs, and what to check for insertion force, retention, wear or binding.
5. **Validate and report.** If CAD files are requested, follow the shared [model, verify, and export workflow](../SKILL.md#model-verify-and-export) for the design and any coupon. Inspect both mating faces and confirm the expected parts are separate, printable meshes. Before approving a sliding pair, check it in the fitted position, including any flip from the print layout. In the fitted pose, run an OpenSCAD intersection or compare the two cross-sections at the same depth from the seam. Verify that there is no solid overlap, the lip captures the wide rail head, the channel is open at the specified ends, and the clearances match the request. A watertight STL or a preview of separated parts cannot catch an inverted profile. For a concept-only answer, include a sketch, starting dimensions, print plan, runnable OpenSCAD example, and fit risks without claiming a print has been tested. Open the [source notes](../references/source-anchors.md) if the user asks for provenance.

Use OpenSCAD for generated geometry. Native STEP export is unavailable. A positive mesh and render check does not establish physical fit, life expectancy, or waterproofing.
