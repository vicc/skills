# Model with OpenSCAD

Create an editable 3D model from dimensions, or revise an existing .scad file. Ask for a PNG to inspect the shape and an STL when you’re ready to slice it.

## Install

```bash
npx skills@latest add vicc/skills --agent codex --skill vicc-model-with-openscad
```

## Try it

> Use $vicc-model-with-openscad to make an 80 × 50 × 12 mm parts tray with 2 mm walls and a 2 mm base. Make those dimensions editable and export a top-view PNG and an STL.

Give dimensions in millimeters and identify the surfaces that need to fit together. For mating parts, verify the fit with a physical print.
