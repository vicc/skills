# Organize My Day

Build a suggested schedule around calendar commitments, deadlines, and the work that needs uninterrupted time.

## Install

```bash
npx skills@latest add vicc/skills --agent codex --skill vicc-organize-my-day
```

## Try it

> Use $vicc-organize-my-day to plan today around my meetings. I need an hour to review a proposal before 3 pm and time to prepare for tomorrow’s demo.

Include fixed deadlines and anything missing from your calendar. You get a draft to review. Calendar edits and RSVPs require a separate request.
